# Security policy

Do not report a security problem in a public issue or a discussion.

## Report a security problem

1. Open the [Security tab](https://github.com/Illumate-ai/illumate-studio-community/security) of this repository.
2. Select **Report a vulnerability**.
3. Tell us the steps that show the problem, and what a person can do with it.

Only you and the maintainers of this repository can see the report.

## Rules for testing

- Test only with your own account and your own data.
- Do not read, change or delete the data of another person.
- Do not stop the service or make it slow.
- Do not send a large number of automated requests.
