# Illumate Studio community

[Illumate Studio](https://studio.illumate.ai) generates 3D furniture from settings. Use this repository to report bugs, request features and ask questions.

This repository holds no source code for Illumate Studio.

## Where to go

| You want to | Go to |
|---|---|
| Ask a question or share an idea | [Discussions](https://github.com/Illumate-ai/illumate-studio-community/discussions) |
| Report a bug | [New bug report](https://github.com/Illumate-ai/illumate-studio-community/issues/new?template=bug_report.yml) |
| Request a feature | [New feature request](https://github.com/Illumate-ai/illumate-studio-community/issues/new?template=feature_request.yml) |
| Delete your account, get a copy of your data, or get back into your account | [New account request](https://github.com/Illumate-ai/illumate-studio-community/issues/new?template=account_request.yml) |
| Report a security problem | [Security policy](SECURITY.md). Do not open a public issue. |

You need a free GitHub account to post here.

## Keep your personal data private

All posts in this repository are public. Search engines can read them.

- Do not post your email address, your password or your session data.
- Do not post a photo that shows a person, a home address or other private data.
- Do not post the personal data of another person.

If you post personal data by accident, edit your post or delete it.

## Rules

- Be polite. Talk about the work, not the person.
- Search for an existing post before you make a new post.
- Put one topic in each post.
- Do not post spam, advertisements or illegal content.

We can edit, close or delete a post that breaks these rules. We can also block an account from this repository.

The [Terms of Service](https://studio.illumate.ai/terms) and the [Privacy Policy](https://studio.illumate.ai/privacy) of Illumate Studio also apply to your use of the service.
